# 积分规则

会员号、事件号和消费引用均为字符串，前导零保留。积分必须正整数，使用Decimal校验后转为整数，不支持小数积分。事件时刻有时区偏移，统一UTC。规则有效窗与积分可用期均为半开区间。
同一时刻先发放，再消费，最后退款；同类按事件编号排序。消费批次按最早到期、最早发放、批次编号依次选择，余额不足时整笔失败。批次在到期时刻立即不可用，不能消费未来发放积分。
退款必须引用同一会员已成功消费，累计退款不得超过原消费。部分退款按原分配的逆序回拨，先回拨最后消耗的批次；未到期恢复，已到期只记过期退款，绝不复活。后续消费使用回拨后的可用余额。同一退款编号重复提交以原因码 REFUND_DUPLICATE 隔离，已恢复积分不翻倍。多笔部分退货无论提交先后，均按事件时刻确定性重放，累计结果只由原消费分配解释。

退货回拨输出三类可追溯结果：退货审计行（含原消费积分 spend_points、累计已退 cumulative_refunded、恢复 restored、过期不恢复 expired_refunded 与校验码）；回拨批次去向 refund_trail（每笔退货在每个原批次上的 points、status=已恢复可用/已过期不恢复、到期时刻 expires、原始行 line）；批次余额轨迹 lot_trail（每批 issued、consumed、restored_refund、expired_refund、natural_expired、remaining，守恒式 发放=剩余+累计消费−退货恢复+自然到期，balanced 逐批标注）。

发布以 publications 单例表保存当前唯一已发布版本（run_id、digest、revision、完整结果快照、published_at）。发布走单条 UPSERT 原子事务：守恒或退货审计不通过返回 422、版本陈旧返回 409，任何失败都保留旧版整行；runs 表的原始结果与输入快照在发布前后逐字节不变。同 run_id+digest+revision 重试返回 replayed=false 的幂等响应。
发放积分=可用积分+已消费积分−全部已退款积分+自然到期积分+过期退款积分。已退款包括有效恢复与过期不恢复。失败消费与失败退款均不改余额，移入隔离。
期末时点默认2026-11-03T00:00:00+08:00，未来事件隔离。示例会员00001：100+80发放，消费120，退款30，其中20恢复、10过期；再消费50后剩余30。
